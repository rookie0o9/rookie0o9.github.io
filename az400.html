exam domain map

Domain 1

Configure Processes and Communications

Activity tracking, collaboration, agile planning. Covered through Azure DevOps board and pipeline configuration.

$ az boards work-item list --project <project>

Domain 2

Design and Implement Source Control

Branching strategy, repository structure, pull request policies. Foundations in the Terraform delivery repo structure.

$ az repos policy list --repository-id <id>

Domain 3

Build and Release Pipelines

The core domain. Plan/apply separation, artefact management, environment gates. Covered in the Terraform backbone series.

$ az pipelines run --name <pipeline>

Domain 4

Security and Compliance

Workload identity federation, secret management, policy-as-code. WIF post covers the credential elimination pattern.

$ az security assessment list --query '[].displayName'

Domain 5

Instrumentation Strategy

Monitoring, alerting, log analytics, feedback loops. Planned: Log Analytics workspace integration and alert rule documentation.

$ az monitor log-analytics query --workspace <id>
